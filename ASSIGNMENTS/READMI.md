# Network Analysis Assignments
The original dataset `anime_info.csv` is provided as a compressed 7-Zip archive:

    anime_info.7z

Before running the assignments, extract the archive and put inside the folder data so that the following file is available:
    data/anime_info.csv

The file `anime_filtered.csv` is not included in the repository because it is generated by Assignment 0.

After running Assignment 0, the following file will be generated:

    data/anime_filtered.csv

## Assignments
* **Assignment 0**: Compute different measures on a large graph.
* **Assignment 1**: Find the communities of your graph.
* **Assignment 2**: Network robustness.
* **Assignment 3**: Sending messages through a network.
